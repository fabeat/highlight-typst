<span class="hljs-title">= Introduction &lt;intro&gt;</span>

In this chapter we cover <span class="hljs-emphasis">*emphasis*</span>, <span class="hljs-emphasis">_also emphasis_</span>,
<span class="hljs-strong">**strong emphasis**</span>, and <span class="hljs-strong">__also strong__</span>.

You can also use <span class="hljs-emphasis">~subscript~</span> and `code`.

A few typographic shorthands: an em-dash <span class="hljs-string">---</span>, an en-dash --,
and an ellipsis <span class="hljs-string">...</span>

Character escapes let you write a literal <span class="hljs-meta">\#</span> in markup, or
a literal <span class="hljs-meta">\*</span> asterisk, or a literal <span class="hljs-meta">\[</span> bracket. The
Unicode escape form works too: <span class="hljs-meta">\u{1f600}</span> renders as an emoji.

Cross-references: see <span class="hljs-symbol">@intro</span> on page <span class="hljs-symbol">@syntax</span> for the syntax
overview, and <span class="hljs-symbol">@built-ins</span> for the standard library.

The label syntax `&lt;intro&gt;` is itself a markup token. So
`<span class="hljs-meta">\&lt;</span>label<span class="hljs-meta">\&gt;</span>` is an escaped label reference, not a label.

The set rule applies a style globally:
#<span class="hljs-keyword">set</span> <span class="hljs-built_in">heading</span>(<span class="hljs-built_in">numbering</span>: <span class="hljs-string">&quot;1.&quot;</span>)

<span class="hljs-title">= Strong styling &lt;strong&gt;</span>

This is <span class="hljs-emphasis">_italic_</span>, <span class="hljs-emphasis">*also italic*</span>, <span class="hljs-strong">__bold__</span>, and <span class="hljs-strong">**also
bold**</span>. Mix and match for <span class="hljs-emphasis">*nested*</span> emphasis.

<span class="hljs-title">= Code with labels</span>

#<span class="hljs-keyword">let</span> <span class="hljs-variable">section</span> = &lt;<span class="hljs-variable">sec</span>:<span class="hljs-variable">main</span>&gt;
#<span class="hljs-keyword">let</span> <span class="hljs-variable">private_var</span> = <span class="hljs-number">42</span>

Use <span class="hljs-symbol">@sec:main</span> to cross-reference the section.

The `&lt;sec:main&gt;` label can be reached via the
ref function, like #<span class="hljs-built_in">ref</span>(&lt;<span class="hljs-variable">sec</span>:<span class="hljs-variable">main</span>&gt;).

<span class="hljs-title">= Em-dash and ellipsis in prose</span>

Typst <span class="hljs-string">---</span> as a single token <span class="hljs-string">---</span> renders as an em-dash.
Multiple dots<span class="hljs-string">...</span> render as a single ellipsis character.
